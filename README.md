
# Living Room Assistant with COCO-SSD

Web application developed with HTML, CSS, JavaScript and TensorFlow.js to detect objects in a living room using the COCO-SSD model.

The application includes three features:
- Remember the last detected position of a remote control.
- Warn when a drink is too close to a laptop.
- Suggest taking a break after prolonged presence.
